# CLI Fixed in v0.1.4

## What Was Wrong

The CLI had incorrect typer argument declarations that caused:
```
TypeError: TyperArgument.make_metavar() takes 1 positional argument but 2 were given
```

## What's Fixed

✅ Simplified typer.Argument() and typer.Option() declarations
✅ Removed verbose help strings that caused issues with typer 0.12+
✅ `zbs generate` now works correctly

## Upgrade Now

```bash
# Uninstall old version
pipx uninstall zettabrain-skills

# Install fixed version (v0.1.4)
pipx install git+https://github.com/zettabrain/zettabrain-skills.git

# Verify
zbs version
# Should show: ZettaBrain Skills version 0.1.0
```

## Technical Details

### Before (Broken)
```python
def generate(
    skill_file: str = typer.Argument(..., help="Path to skill file (.md)"),
    input_text: str = typer.Option(..., "--input", "-i", help="Input text for generation"),
    ...
)
```

### After (Fixed)
```python
def generate(
    skill_file: str,
    input: str = typer.Option(..., "--input", "-i"),
    ...
)
```

The issue was:
- typer 0.12+ changed how `make_metavar()` works
- Verbose help strings in Argument/Option caused incompatibility
- Simplified declarations work across typer versions
